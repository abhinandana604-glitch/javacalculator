# Calculator

A responsive calculator built with HTML, CSS and JavaScript. It supports addition, subtraction, multiplication, division, modulo, keyboard input and a recent-calculations list saved in the browser.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `calculator`).
2. Extract these project files and upload **all files directly into the repository root**. Make sure `index.html` is at the top level.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/calculator/`.

## Note
This is a static website, so it works on GitHub Pages without Java, Maven, a server or a database. Calculation history is stored in the browser using localStorage; it is not synced between devices or browsers.
